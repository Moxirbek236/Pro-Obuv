ASOSIY FAYLLAR (MAIN APPLICATION FILES):
─────────────────────────────────────────────────────────────────────────────

1. app.py (ASOSIY ILOVASI)
   - Dashtu Flask ilovasining asosiy fayli
   - API endpoints va marshruttalarni (routes) belgilaydi
   - Database bilan bog'lanishni boshqaradi
   - Foydalanuvchi autentifikatsiyasini amalga oshiradi
   - Buyurtma, tovar, xabar va chat sistemalarini boshqaradi
   - Admin panelini xalqaro tilga tarjima qilishni boshqaradi
   - ~22,000 qatorda kod bor
   - O'rnida: app.py.bak (zaxira nusxasi)

2. config.py
   - Ilovaning sozlamalarini (configuration) saqlaydi
   - Database URL, parollar, API kalitlari
   - Turli muhitlar uchun sozlamalar (development, production)
   - Tillar va lokalizatsiya parametrlari

3. utils.py
   - Foydalanish qilinadigan funksiyalar (utility functions)
   - Xalqaro tilga tarjima funksiyalari
   - Vaqt, sanalar bilan ishlash funksiyalari
   - Ma'lumotlarni validatsiya qilish funksiyalari
   - Ruxsat boshqarish funksiyalari

4. i18n.py
   - Xalqaro tilga tarjima (Internationalization) uchun modul
   - Tillar orasida o'tishni boshqaradi
   - Matn tarjimalari bilan ishlaydi
   - Tilga mos sozlamalarni qo'llaydi

5. location_service.py
   - Geolokatsiya xizmatini boshqaradi
   - Foydalanuvchining manzili bilan ishlaydi
   - Dostavka zonalarini aniqlaydi
   - Xarita bilan muloqotni amalga oshiradi

6. sms_helper.py
   - SMS xabarlarini yuboradi
   - Foydalanuvchiga bildirishnomalarni jo'natadi
   - OTP (bir martalik kodi) yuborishni boshqaradi

7. payment_settings.py
   - To'lov tizimining sozlamalarini o'rnatadi
   - To'lov vositalarini (Stripe, Click, Payme) konfiguratsiyalaydi
   - To'lov ma'lumotlarini xavfsiz saqlaydi

8. database.sqlite3
   - ASOSIY DATABASE FAYLI
   - Barcha ma'lumotlar shu yerda saqlanadi:
     * Foydalanuvchilar (users)
     * Tovarlar (menu_items)
     * Buyurtmalar (orders)
     * Xabarlar (news)
     * Ratinglar (ratings)
     * Chat xabarlar (chat messages)
     * Va boshqa ma'lumotlar
   - To'g'ri nusxalari: database.sqlite3-shm, database.sqlite3-wal
